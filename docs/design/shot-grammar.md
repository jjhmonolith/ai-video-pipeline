# 촬영 문법 · 어휘와 규칙

출처는 두 영상이다. 둘 다 화자 1인이고 특정 서비스를 홍보한다. **어떤 어휘와 구조를 쓰는가는 확정되지만, 그것이 결과를 개선하는가는 확정되지 않는다.** 우리 파이프라인에서 시험해야 한다.

- `AI 영화 제작 가이드 AI 영상 퀄리티 3배 높여주는 8가지 비법 공개` · AI 아스트라 · 2026-08-21 · **자동자막**
- `이걸 왜 이제야 AI 영상에도 이제 PPM이 가능합니다 (Newtake)` · 신동댕동 · 2026-08-14 · 수동자막

자동자막이라 고유명사가 깨져 있다. 서비스명과 모델명은 인용하지 않는다.

## 0. 두 출처가 충돌한다

**캐릭터 시트를 얼마나 자세히 만들 것인가에서 정반대를 말한다.**

| | 신동댕동 | AI 아스트라 |
|---|---|---|
| 구성 | 전신 1컷, 6면 턴어라운드, 표정 포함 7컷, 의상 분해도, 원단 재질, 컬러 팔레트 색상 코드 | **딱 3패널.** 전신 정면(머리 없는 마네킹), 전신 후면, 얼굴 클로즈업 |
| 근거 | 다른 옷·다른 환경에 배치해도 유지되는 앵커 [04:07](https://www.youtube.com/watch?v=cnE_I8jtUxY&t=247s) | 정보량이 늘면 도플갱어가 생긴다. 시트에 인물 이미지가 많을수록 모델이 여러 명으로 해석한다 [00:02:27](https://www.youtube.com/watch?v=sHs0_iZJxHk&t=147s) |

AI 아스트라는 예전에 자세한 시트를 만들었고 `시트가 화려할수록 좋은 줄 알았는데 정반대였다` 고 말한다. 정면에서 머리를 뗀 이유는 `정면 얼굴 정보는 세 번째 패널이 이미 훨씬 크게 담당` 하므로 중복이라는 것이다.

**해소되지 않았다.** 둘 다 단일 화자이고 교차검증이 없다. 우리 파이프라인은 생성을 통제하므로 **직접 비교할 수 있다.** 같은 인물로 3패널 시트와 다패널 시트를 만들어 같은 컷을 뽑고 도플갱어 발생률을 세면 된다. 그 전까지는 어느 쪽도 규칙으로 굳히지 않는다.

기본값은 **3패널**로 둔다. 적은 쪽이 실패했을 때 늘리기 쉽고, 도플갱어는 우리가 아직 겪지 않은 실패라 예방 비용이 싸다.

## 1. 주 피사체 시트

캐릭터가 없는 영상이 있다. 1971 대선 건이 그렇다. 익명 군중뿐이고 얼굴이 중요하지 않다.

**규칙은 세 단계로 내려간다.**

1. 인물 캐릭터가 있으면 **캐릭터 시트**를 만든다
2. 없으면 컷을 관통하는 **주 피사체 시트**를 만든다. 장소, 물건, 기계 무엇이든 반복 등장하며 일관성이 필요한 것
3. 그것도 없으면 **생략한다.** 매 컷 다른 장소이고 반복되는 대상이 없다면 시트는 비용만 된다

주 피사체 시트는 캐릭터 시트와 같은 3패널 원칙을 따른다. 정면, 후면 또는 반대편, 세부 클로즈업.

## 3. 어휘

화자가 쓰는 용어를 그대로 쓴다. 자동자막이라 표기가 흔들린 것은 표준 표기로 적었다.

### 무브먼트 · 카메라가 무엇을 하는가

| 용어 | 동작 | 쓰는 자리 |
|---|---|---|
| 스태틱 샷 | 움직이지 않음 | 화자가 `모든 것보다 가장 앞선 것` 이라고 부른다. 안 움직이는 것도 선택이다 |
| 달리 인 | 인물을 향해 밀고 들어감. 실제 공간을 통과하는 느낌 | 깨닫는 순간, 각성 |
| 슬로우 줌 인 | 카메라는 고정, 렌즈만 당김. 공간이 눌리며 압박감 | 조용한 긴장 |
| 돌리 줌 | 카메라는 물러나고 렌즈는 줌 인. 인물 크기는 그대로, 배경만 뒤틀림 | 충격, 발밑이 꺼지는 순간 |
| 아크 샷 | 인물 주위를 곡선으로 돎 | 첫 등장, 공간을 한 번에 설명 |
| 사이드 트래킹 | 인물 옆으로 나란히 달림 | 이동의 리듬 |
| 팔로우 샷 | 인물 뒤를 어깨 높이로 따라감 | 이동, 추격. 몰입도가 가장 높다 |
| 리버스 트래킹 | 인물 앞에서 뒤로 물러나며 찍음 | 걸으며 대사하는 장면 |
| 휩 팬 | 빠르게 휘둘러 잔상 | 컷 전환, 타격감 |
| 크레인 업 | 수평 유지한 채 수직으로 솟음 | 장면을 닫을 때, 엔딩 |
| 드론 풀백 | 뒤로 그리고 위로 동시에 | 규모를 보여줄 때. 엔딩 컷의 정석 |
| 푸시 스루 | 문이나 창을 통과해 다른 공간으로 | 장면 전환을 편집이 아니라 카메라로 |
| 핸드헬드 | 미세한 흔들림 | 현장감, 불안, 다큐. **AI 티가 확 줄어든다** |

## 4. 컷 길이는 감이나 고정표가 아니라 4단계 연출 판단이다

`[00:12:54](https://www.youtube.com/watch?v=sHs0_iZJxHk&t=774s)`

아래 수치는 조사 출처가 제시한 경험적 출발점이며 validator 범위가 아니다.
슬로모션, 시간정지, bullet-time orbit, 타임랩스, 생략 편집처럼 현실 시간과 편집
시간이 다른 shot에는 그대로 적용하지 않는다. 현행 정본은
`stage3-stage6-production-contract.md`의 LLM timing 계약이다.

| 컷의 목적 | 조사 출처의 일반적 예시 |
|---|---|
| 사물 클로즈업, 인서트 | 3-4초 |
| 인물 이동, 액션 | 5-7초 |
| 감정 실린 표정, 대사 | 7-10초 |
| 공간 설정 샷 | 5-8초 |
| 의도적 롱테이크 | 10초 이상, **단 무브먼트는 반드시 하나** |

### 왜 길게 뽑으면 안 되는가

화자가 세 가지를 든다.

1. **모델이 주어진 시간을 채우려 한다.** 30초를 달라고 하면 30초 분량의 사건을 지어낸다. 프롬프트에 적은 내용이 7초짜리인데 30초를 요청하면 나머지 23초는 모델이 만들어낸다. 인물이 흐르고 정적이 길어지는 영상이 그래서 나온다
2. 상업 영화 평균 컷 길이가 3-5초다. 액션은 더 짧다
3. **수정 비용.** 30초를 통으로 뽑았는데 20초 지점에서 무너지면 30초를 다시 뽑아야 한다. 7초 단위면 7초만 다시 뽑는다

**1번이 우리 관측과 정확히 맞는다.** v2의 T2는 13.7초를 요청했고 프롬프트 내용은 `한 사람이 묶음을 놓는다` 였다. 모델이 남는 시간을 손 클로즈업으로 채웠다. 나는 이것을 FL2VA의 한계로만 진단했는데, **요청 길이와 내용 분량의 불일치**가 원인의 절반이었을 가능성이 크다.

우리 v3도 15초 테이크를 뽑아 잘라 썼다. 이 규칙대로면 잘못된 방식이다.

## 6. 우리 파이프라인에 넣은 것

### 옛 9~10단계 파이프라인 (supercar-review v1~v3)

- `shot_grammar_gate.py` 가 shot card를 검사한다. 카메라 네 조각, 무브먼트 하나, 어휘 목록, 컷 목적별 듀레이션
- 주 피사체 시트 규칙은 `subject_sheet` 필드로 선언한다
- 캐릭터 시트 3패널 대 다패널은 미해결로 두고 기본값만 3패널

### 새 9단계 파이프라인 (2026-08-25 개편, Stage 05.5 추가)

`01-premise / 02-sheet / 03-scenario / 04-shot-design / 05-plate / 05.5-motion-prompt / 06-motion / 07-edit / 08-review`

**들어간 것.**

- 기존 `beat_seconds`와 `why_this_long`은 legacy attempt 감사에만 남는다.
- 신규 3단계는 신별 추정 범위와 temporal intent를 쓰고 정확한 shot 길이는 정하지 않는다.
- 신규 4단계 LLM이 intent·POV·blocking·coverage와 함께 정확한 edit target, handle,
  temporal mode를 정하며 deterministic compiler는 H3 frame grid만 맞춘다.
- 어휘 세 축과 카메라 네 조각은 `shot_design.py`가 shot card로 만들고 semantic check가 검사한다.

**현재 경계.**

- 카메라 네 조각과 장면/연기 지시 분리는 `04-shot-design`에 들어갔다
- 무브먼트 16 / 앵글 6 / 사이즈 9의 허용 어휘는 아직 `shot_grammar_gate.py`가 소유한다. 계약 데이터로 이동하는 일은 남았다

### 3패널 논쟁의 현재 상태

**우리는 다패널 쪽으로 갔다.** 현행 `02-sheet`의 캐릭터 보드는 턴어라운드 5뷰에 헤드 스터디 6뷰다. AI 아스트라가 경고한 도플갱어 위험을 무릅쓴 셈이다.

지금까지 만든 보드 넷에서 **도플갱어는 관측되지 않았다.** 인물이 하나로 유지됐고, 비인간 캐릭터인 허스키에서도 꼬리와 귀가 각도마다 맞았다.

다만 이것은 **보드 안에서의 일관성**이지, 그 보드를 물려 만든 컷에서 인물이 유지되는지는 아직 안 쟀다. `05-plate` 까지 가야 판정할 수 있다. 그때까지 미해결로 둔다.
