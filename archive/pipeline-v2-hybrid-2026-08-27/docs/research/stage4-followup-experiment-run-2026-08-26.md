## M1 사후 입력 검수와 무효화

사람 평가 입력 전 검수에서 모든 배관공 task 이미지의 배관·커플링이 해당 렌치가 물기에는 너무 크고 두꺼운 것으로 확인됐다. 또한 렌치 작용면은 대상 축과 직교해야 하는데, 도구 형태를 카메라에 보여주려는 사선의 3/4 구도가 고정 입력에 들어갔다. 이는 H3 후보의 성능 차이가 아니라 모든 셀이 공유한 입력 기하 실패다.

- 사람 점수·승자 입력: 0건
- M1 24개와 AI 봉인 파일: 후보 비교와 실패 분석용으로 평가·보존
- M1의 reference pack 및 last-frame 일반 효과 추론: 이 패킷만으로 확정 금지
- L1 18개: 사람 평가 완료, `review_complete: true`, 사람 승자 H
- M1 재실험: 용량비 1.15 이상, 안착 전 여유, 양쪽 턱 접촉, 작용면–대상 축 90°±5°를 통과한 새 이미지 이후에만 허용

## 평가 분리

AI 평가는 사람 응답을 읽기 전에 조건 키 없는 후보 코드와 14개 시점 프레임으로 작성했다. 각 주제의 `comparison/ai-review.sealed.json`과 SHA-256 `comparison/ai-review.seal.json`에 봉인되어 있다. 사람용 HTML은 이 파일과 조건 키를 읽지 않는다.

사람 평가 페이지는 원래 다음 세 그룹으로 만들어졌다.

- 펜트하우스 · 호스트 이동: A–R, 18개
- 배관공 · 렌치 안착: A–L, 12개
- 배관공 · 커플링 소회전: A–L, 12개

L1은 사람 평가가 완료됐다. M1 두 그룹도 후보 간 상대 품질과 실패 양상을 기록하는 진단 평가를 계속한다. M1의 점수와 승자는 이 입력 패킷 안에서는 유효하지만, 공통 입력 기하가 실패했으므로 요인의 일반 효과를 확정하는 근거로 단독 사용하지 않는다.

각 후보 아래에 점수, 오류 체크, 자유 피드백이 있고 그룹별 승자, 순위, 종합 피드백을 입력한다. 영상 재생이 96%에 도달하면 완주로 기록된다. 입력은 브라우저 `localStorage`와 프로젝트의 `human-review-response.json`에 자동 저장된다. 모든 후보 완주·점수와 그룹 승자가 채워진 경우에만 `review_complete`가 `true`가 된다.

## 사람 평가 후 분석 순서

1. 펜트하우스 `human-review-response.json`의 `review_complete: true` 확인 완료
2. 배관공은 24/24 완주, 23/24 점수, 두 그룹 `no_winner` 확인. M1-turn D 점수 하나가 비어 있어 `review_complete: false`
3. AI 봉인 파일 해시 재검증
4. `blind-key.json` 공개
5. 같은 시드의 `first_only / paired` 결과 비교
6. L1의 camera policy와 last-frame 효과 집계
7. M1의 후보·실패 패턴을 진단하고, 요인 효과는 입력 기하 한계를 명시해 탐색적으로만 보고
8. 3개 시드 중 2개 이상 승리와 치명 오류율 기준으로 이동 장면의 4단계 기본 정책 결정

M1은 새 입력판으로 별도 재실험하기 전까지 결론을 내리지 않는다.

통합 결과와 4단계 정책 결정은 `stage4-followup-experiment-analysis-2026-08-26.md`에 기록했다.
